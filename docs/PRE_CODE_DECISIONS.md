## External facts that do not reopen these decisions

- Each downloaded artifact's SHA-256 and exact licence text are recorded before it enters the dependency cache. A mismatch blocks acquisition.
- Spigot-compatible legacy fixtures are produced privately under the upstream tool/licence process; no server binary is committed or distributed.
- Vulcan remains optional until the operator supplies a lawfully licensed runtime/API. The neutral SPI and safe no-provider path are implementable without it.
- Legal review must adapt executed notices/EULA/privacy language to the deployment jurisdiction before public/commercial release. Until then the repository and all project output remain private, proprietary and non-redistributable.

No unresolved owner or architectural choice in this register blocks M01. External acquisition and legal-execution checks are deterministic entry/release gates, not permission to weaken scope.
