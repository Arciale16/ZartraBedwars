# ADR-0013: Clean-room addon and migration provenance

**Status:** Accepted
**Date:** 2026-07-14
**Resolves:** RC-043, RC-071
**Requirements:** `ZBW-READY-012`, `ZBW-READY-020`

## Decision

Preserve every addon capability while using third-party names/pages only as factual functional references. Runtime names, code, assets, text, layouts and balance are original/neutral; migration accepts only operator-authorized lawful data. Provenance, trademark and release legal review are mandatory.

## Consequences and controls

Clean-room work may take longer and exact protected presentation is intentionally not reproduced, while functional scope remains. Repository/binary/content similarity scans, 49/473 coverage, asset/dependency manifests and release checklist block copied or unlicensed material.
