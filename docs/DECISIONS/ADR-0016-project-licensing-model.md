# ADR-0016: Project licensing model

**Status:** Accepted
**Date:** 2026-07-14
**Resolves:** RC-066
**Requirement:** `ZBW-READY-019`

## Decision

Private/commercial implementation, premium modules, assets and product documentation are proprietary, all rights reserved. Public API/SDK redistribution occurs only after separate owner-executed terms; Apache-2.0 is the approved recommendation. Addons use their authors' lawful licences but receive no Zartra proprietary asset/internal/mark rights.

## Consequences and controls

There is no implied open-source grant. Development may proceed privately; public/commercial release waits for executed EULA/privacy/SDK/trademark/contributor terms, compatible SBOM/notices/provenance and release-checksum approval under `docs/PROJECT_LICENSING_RECOMMENDATION.md`.
