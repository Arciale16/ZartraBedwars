# Mode framework M10

The bounded registry owns stable IDs, versions, localized metadata, availability, layout/player
bounds, capabilities, typed schema and explicit later-milestone bindings. Duplicate or stale
registration fails closed. Solo 8x1, Doubles 8x2, 4x3, 4x4, 2x4, custom 12x3 and 64x4 layouts
use one semantic-team contract. Named modes may register metadata, but their mechanics remain M11.
