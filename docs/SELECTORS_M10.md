# Selectors M10

Selectors use typed arena ID, definition revision, map, mode, layout, capacity, health, world
readiness and lifecycle. They never infer compatibility from names, colors or lore. Queries
support typed filtering, normalized search, configurable order, pagination and revision. Pages
expose ready/empty state plus exclusion evidence. Clicks create revision-bound tokens and stale
views fail closed. The 28 additive M10 actions generate equivalent M09 command and GUI surfaces.
