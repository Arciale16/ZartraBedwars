# M10 matchmaking administrator guide

Configure queue/request/actor ceilings, expiries, aging, selector order/page size, enabled
modes/layouts, spectator policy, Team Selector and Compass policy through typed composition.
Use the generated diagnostics/reservations commands and GUI pages with granular M03 permissions.
On shutdown stop admission, drain bounded workers and release unconfirmed holds. Never treat M10
local state as a proxy-wide queue.
